# arxiv-daily

Auto-generated daily digest of arXiv papers (cs.CV / cs.RO / cs.AI), with Chinese translations, figure previews, and code/project links.

**Live site:** https://postoday.github.io/arxiv-daily

This repo is updated automatically every weekday by [arxiv-daily-tool](https://github.com/postoday/arxiv-daily-tool). Do not edit files here manually — they will be overwritten on the next run.

## Structure

```
data/               — raw JSON per day (papers + metadata)
index.html          — homepage (latest day)
archive/            — per-day archive pages
assets/             — CSS and JS
```
